# 怎么验证它真的成功了

## 开始之前

需要准备：

- 一台已经 root（KernelSU）的手机，本项目在 realme RMX5010 / ColorOS 16 上验证；
- 一个音乐软件（验证时用网易云音乐）；
- 一个能语音的游戏（验证时用王者荣耀），或者任意录音应用；
- 一个能听你说话的队友，也可以自己录音验证。

判断标准是「队友能不能听到你放的歌」。送进麦克风的就是你实际在放的那首。

## 第一步：确认 root 还在

**在哪做**：Termux 终端，任何目录都行。

**执行什么**：`su -c id`

**看到什么算成功**：输出里有 `uid=0(root)`。

**不过怎么办**：见 [runbook.md](runbook.md) 症状一。这一项不过，后面全是白做。

## 第二步：确认界面能正常用

**在哪做**：手机桌面上点开本工具。

**执行什么**：把顶部开关打开；在下面的列表里选中你的音乐软件。

**看到什么算成功**：开关能拨动；界面显示「已打开」；列表里能找到并选中你的音乐软件。开关打开后若显示「操作没成功：…」，把提示记下来。

**顺带看通知栏**：开关打开后，下拉通知栏能看到本工具的常驻通知，上面有一个「关闭」按钮，点它能直接关掉。

## 第三步：确认钩子已经装上

**在哪做**：Termux 终端。

**执行什么**：

```
su -c 'ls /data/misc/audioserver/libmcpayload.so'
```

能看到这个文件就说明工具已释放。

如果提示找不到，先在界面上把开关打开一次，工具会自动释放。

**看到什么算成功**：输出形如「启用中 采集=… 注入=… 音轨=…」。

**不过怎么办**：见 [runbook.md](runbook.md) 症状一。

## 第四步：核心功能验证（最重要）

这一步验证「队友到底听见了什么」。

**要做什么**：

1. 确认界面上的总开关是**打开**的；
2. 戴上耳机开始放歌（歌从耳机里正常响，这是对的）；
3. 进游戏的语音房间；
4. 对着麦克风位置**不要说话**，在旁边拍手或说话作对照；
5. 问队友两个问题：**能听见我放的歌吗？能听见我这边的环境声吗？**

**看到什么算过**：

| 队友的回答 | 结论 |
| --- | --- |
| 能听见歌，听不见环境声 | **通过** |
| 能听见歌，也能隐约听见环境声 | **降级通过**，可用，记录这个现象 |
| 听不见歌 | **不通过**，见 [runbook.md](runbook.md) 症状一 |
| 能听见歌，同时听见游戏枪声或队友自己的声音 | **不通过**，这是回音，见症状二 |

**顺带确认**：你自己戴耳机听到的歌应该完全正常。

## 第五步：确认关掉以后能恢复

同样重要，务必做。

**要做什么**：

1. 在界面上把开关**关闭**；
2. **不重启游戏、不重启手机**；
3. 对着麦克风正常说话，问队友能不能听见你。

**看到什么算过**：队友能正常听见你说话，且听不见歌了。

## 不依赖队友的自测方法

手边没队友时，用录音自己验证。

**在哪做**：手机上的录音应用。

**执行什么**：开关打开、正在放歌时录 10 秒；关掉开关，再录 10 秒。

**看到什么算成功**：第一段录到的是歌，第二段是你周围的环境声。两段内容明显不同。

**说明**：部分录音应用自带降噪，可能影响判断，优先用系统自带的。

## 命令行自测（开发用）

需要一段可复现的录音。手机上没有独立的录音命令行工具，本方法仅记录验证时用过的做法。

**核心判据**：录音数据按 32 位浮点解读。开关开着时，波形幅度（均方根）应显著高于关着时；实测开是 0.68、关是 0.0012，差约 570 倍。

## 换了机型要重新求地址

工具的库内地址按本机实测值写死，换机型要重新测两个地址：

| 关口 | 找什么 |
| --- | --- |
| 出口 | `libaudioflinger.so` 里 `Track::getNextBuffer` 的地址 |
| 入口 | `libaudiohal@aidl.so` 里 `StreamInHalAidl::read` 的地址 |

做法：用带调试符号的同一份库，读出这两个函数的地址，填进 `native/mcpayload.c` 顶部的 `CAP_OFF` 与 `INJ_OFF`。

## 判定标准汇总

| 档位 | 判据 | 算不算成功 |
| --- | --- | --- |
| 第一档 | 队友听见歌，完全听不见环境声 | 算，最好 |
| 第二档 | 队友听见歌，环境声残留但很微弱 | 算，可接受 |
| 失败 | 听不见歌，或听见游戏音效、回音 | 不算 |

关于延迟：**不设硬指标**。只看队友听到的歌是不是连续、不卡顿、不中断。
