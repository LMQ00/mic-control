# 怎么验证它真的成功了

## 开始之前

需要准备：

- 一台已经 root（KernelSU）的手机，本项目在 realme RMX5010 / ColorOS 16 上验证；
- 手机上装好 LSPosed；
- 一个音乐软件（验证时用网易云音乐）；
- 一个能语音的游戏（验证时用王者荣耀）；
- 一个能听你说话的队友，或者你自己录音验证。

**两件先知道的事**：

1. 判断标准是"队友能不能听到你放的歌"。送进麦克风的就是你实际在放的那首。
2. 模块要**重启一次手机**才会被框架加载。第一次验证之前先重启，第零步就是确认这件事。

## 第零步：确认模块已被加载

这一步是后面所有验证的前提，**必须先做**。

**在哪做**：手机上的 LSPosed 管理器界面。

**执行什么**：打开管理器进模块列表，确认能看到本工具（名字是"麦克风控制"），把它的开关打开，并且**在作用范围里勾上你要测的应用**——音乐软件和游戏都要勾，缺一个都不行。

如果列表里**看不到**本工具，**重启一次手机**再看。

**看到什么算成功**：列表里有本工具且已启用，作用范围里同时有你的音乐软件和游戏。

**不过怎么办**：见 [runbook.md](runbook.md) 症状一。

## 第一步：确认 root 还在

**在哪做**：手机上的 Termux 终端，任何目录都行。

**执行什么**：`su -c id`

**看到什么算成功**：输出里有 `uid=0(root)`。

**不过怎么办**：root 出了问题，先别往下做，看 [runbook.md](runbook.md) 症状一。这一项不过，后面全是白做。

## 第二步：确认界面能正常用

**在哪做**：手机桌面上点开本工具。

**执行什么**：看界面显示是否正常；把顶部开关打开；在下面的列表里选中你的音乐软件。

**看到什么算成功**：界面上有一个总开关和一个应用列表；开关能拨动；列表里能找到并选中你的音乐软件。

**顺带看通知栏**：开关打开后，下拉通知栏应该能看到本工具的常驻通知，上面有状态文字和一个"关闭"按钮，点它能直接关掉开关，不用回到应用界面。

**不过怎么办**：列表是空的，说明读应用列表的权限没生效；通知栏没出现，多半是通知权限被拒。两者都见 [runbook.md](runbook.md)。

## 第三步：核心功能验证（最重要）

这一步验证"队友到底听见了什么"。

**要做什么**：

1. 确认界面上的总开关是**打开**的；
2. 确认列表里已经选中你的音乐软件；
3. 戴上耳机开始放歌（歌从耳机里正常响，这是对的）；
4. 进游戏的语音房间；
5. 对着麦克风位置**不要说话**，可以故意在旁边弄点声音（拍手、说话）作对照；
6. 问队友两个问题：**能听见我放的歌吗？能听见我这边的环境声吗？**

**看到什么算过**：

| 队友的回答 | 结论 |
| --- | --- |
| 能听见歌，听不见环境声 | **通过**，最好的情况 |
| 能听见歌，也能隐约听见环境声 | **降级通过**，可用，但请记录这个现象 |
| 听不见歌 | **不通过**，看 [runbook.md](runbook.md) 症状一 |
| 能听见歌，同时也听见游戏枪声或队友自己的声音 | **不通过**，这是回音，看 [runbook.md](runbook.md) 症状二 |

**顺带确认**：你自己戴耳机听到的歌应该完全正常。如果连你自己听歌都出问题，也属于故障。

## 第四步：确认关掉以后能恢复

这一步同样重要，务必做。

**要做什么**：

1. 在界面上把开关**关闭**；
2. **不重启游戏、不重启手机**；
3. 对着麦克风正常说话，问队友能不能听见你。

**看到什么算过**：队友能正常听见你说话，且听不见歌了。

**这一项必须测**：它验证开关即时生效、可以退回去。不过的后果比较严重——一旦打开就关不掉。

## 不依赖队友的自测方法

手边没队友时，可以自己验证。

**在哪做**：手机上的系统录音机（或任意录音应用），不需要电脑。

**执行什么**：开关打开、正在放歌时，录一段 10 秒左右；然后关掉开关，再录一段同样时长。

**看到什么算成功**：第一段录到的是歌，第二段录到的是你周围的环境声。两段内容明显不同，说明开关确实起作用了。

**说明**：这个方法和"队友听见什么"是同一套道理，可以互相替代。注意部分录音应用自带降噪，可能影响判断，优先用系统自带的。

**已知限制**：用 `MediaRecorder` 录音的应用（很多系统录音机属于此类）不在覆盖范围内，可能测不出效果，这是已知限制、不是配置错误。另外，开发机 Termux 里虽然装了 ffmpeg，但它不带安卓的音频输入设备，**不要**试着用 ffmpeg 在命令行直接录麦克风，那条路走不通。

## 判定标准汇总

| 档位 | 判据 | 算不算成功 |
| --- | --- | --- |
| 第一档 | 队友听见歌，完全听不见环境声 | 算，最好 |
| 第二档 | 队友听见歌，环境声残留但很微弱 | 算，可接受 |
| 失败 | 听不见歌，或听见游戏音效、回音 | 不算 |

关于延迟：**不设硬指标**。只看一条——队友那边听到的歌是不是连续、不卡顿、不中断。连续可听就算过。
