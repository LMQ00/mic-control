# 声音怎么走

## 一、手机里的声音分两股

- **往外放的**：音乐、游戏音效、提示音，都走这条路，最后进你的耳机或扬声器。
- **往里收的**：麦克风收到的声音，走这条路进到应用里，比如语音通话、录音机。

平常这两股互不相干。你在耳机里听到的歌，麦克风是听不见的。这个工具做的事，就是**在中间搭一条支路，把往外放的声音引到往里收的入口**。

## 二、怎么引过去

手机上每个应用互相独立，不能直接递东西。分三步做：

**第一步，在音乐软件那边抄一份。**

音乐软件放歌，必须把声音交给手机系统。工具就在它交出去的那一刻顺手抄一份。抄一份不影响原来那份，你戴耳机听歌一切正常。

**第二步，把抄来的声音送到游戏那边。**

两个应用互相不通，中间要有一条路。工具在两头各开一个口，用手机内部的一条私有管道连起来，把抄到的声音实时送过去。

**第三步，在游戏那边，交给要麦克风的人。**

游戏读麦克风时，工具把管道里的音乐塞给它。游戏拿到的数据，格式和它平时拿到的麦克风数据完全一样，分不出区别，直接编码发给队友。

结果就是：**你耳机里有歌，队友耳朵里也有歌，真实麦克风的声音没有任何人去读。**

## 三、必须指定一个音乐软件

如果不限定来源，把"整台手机正在放的所有声音"都抄一份，那么游戏的枪声、脚步、系统提示音全都会一起送进麦克风。队友会听到：你放的歌，加上他自己刚说的话，加上游戏里的枪声——这就是**回音**。

界面上必须选中一个音乐软件，工具只抄它的声音。这一步不能省。

## 四、作用范围

工具只管**你在框架里勾选的那些应用**，不是整台手机。

- 勾了的应用，开关打开时才会被接管；没勾的，麦克风照常是真的。
- 系统收发声音的那个程序，工具够不着，不在范围内。
- 想让某个应用生效，先在框架里勾选它。**新勾的应用要重启一次手机才生效**，和模块本身一样。

范围限定带来的好处：只抄你指定的那一个音乐软件，游戏的音效不会被送回去，不会有回音。

## 五、开关关掉时

关掉开关，工具立刻停止往麦克风里塞音乐：

1. 游戏再读麦克风，拿回的是它本来该拿到的真实声音；
2. 音乐那边也不再抄声音。

不用重启手机，**也不用重启游戏**。工具在每次录音的那一刻都会重新看一眼开关，关掉就立刻恢复。关掉以后你说话，队友正常能听见。

## 六、出错时的两个兜底

这类工具最怕帮倒忙。留了两层保护：

- **管道里暂时没声音时**（比如你还没开始放歌），游戏读到的还是它原本该读到的内容，不是一片空白。这样万一机制没生效，你的游戏语音照样能用。
- **读不到设置时**，工具一律当成"开关是关的"处理，让麦克风保持正常工作。宁可不出效果，也不让你处于"以为关了、其实没关"的状态。

## 七、需要 root

普通应用被系统限制，不能插手别的声音：既不能抄别人正在放的声音，也不能换掉别人读到的麦克风数据。要越过这两条限制，只能在系统层面动手，这就需要 root。风险与权限用途见 [security.md](security.md)。

## 八、词对照

| 文档里的词 | 说白了就是 |
| --- | --- |
| 往外放的 / 输出 | 手机放声音的那条路 |
| 往里收的 / 输入 | 应用从麦克风读声音的那条路 |
| 抄一份 / 截取 | 把某个应用正在放的声音复制一份出来 |
| 管道 | 两个应用之间那条私有的传声通道 |
| 换掉 / 替换 | 把游戏读到的麦克风数据换成别的内容 |

## 九、现在做到哪了

以下都是实机验证过的，不是推测：

- 王者荣耀确实用 Java 层接口读麦克风（它的 5 个代码包里都有录音读取调用），"在录音读取处换数据"有真实作用对象；
- 网易云音乐确实用 Java 层接口放声音，"抄音乐输出"也有真实作用对象；
- 安装包能自动构建并装到手机上，**签名已固定**，新版可以直接覆盖安装，不用先卸载；
- 模块确实被框架加载进目标应用，播放和录音两边的接口都挂上了钩子（各 7 个）；
- 开关和选择确实能从界面传到运行在别的应用里的工具代码。这一条曾经不成立：界面以前用私有方式保存设置，工具那边不报错、只是一直读到默认值，表现就是"钩子都挂上了却从来不生效"。改成框架能读的方式后已修好；
- 音乐那边的管道口子已经建立，抄到的声音确实在往外送。

**还差的验证**：在被勾选的应用里做一次"开关开、开关关"的录音对比，以及游戏内语音的实听确认。步骤见 [testing.md](testing.md)。

**一个覆盖不到的情况**：用 `MediaRecorder`（系统提供的一种录音方式）录音的应用管不了，它的数据不经过工具能插手的那一层。王者荣耀这类游戏用的是另一种接口，在范围内。详见 [runbook.md](runbook.md)。
