# 声音怎么走

## 一、两条路

- **往外放的**：音乐、游戏音效、提示音，最后进耳机或扬声器。
- **往里收的**：麦克风收到的声音，进到应用里，比如语音通话、录音机。

平常这两股互不相干。你在耳机里听到的歌，麦克风听不见。这个工具在中间搭一条支路，把往外放的声音引到往里收的入口。

## 二、接在哪一层

两条路都经过系统里一个专门收发声音的程序，叫「声音服务」。所有应用放声音、读声音，最后都由它经手。

工具接在它内部的两个关口：

- **出口**：各应用放的声音在这里汇总，工具在这儿抄一份；
- **入口**：应用读麦克风时从这儿取数据，工具在这儿换成音乐。

接在这一层，游戏那边什么都不用改，也看不到异常。它读麦克风拿到的就是音乐。

## 三、认出该抄哪一路

出口汇总的是一堆应用混在一起的声音。全抄的话，游戏的枪声、队友的声音都会进麦克风，形成回音。

声音服务给每一路声音都记了所属应用。工具按这个标记只抄你选中的那个应用，其余不碰。界面上必须选一个音乐软件。

## 四、开关做什么

开关的动作是装与不装：

- 打开：工具往两个关口写入一小段跳转指令，声音改道走工具；
- 关闭：把原始指令原样写回，一切照旧。

两边都不重启声音服务，正在放的歌不断。

## 五、要 root

普通应用被系统隔离，碰不到别人正在放的声音，也改不了别人读到的麦克风数据。这两件事都要在系统层面动手，需要 root。权限用途与风险见 [security.md](security.md)。

## 六、词对照

| 文档里的词 | 说白了就是 |
| --- | --- |
| 声音服务 | 系统里专门收发声音的那个程序 |
| 出口 | 应用放声音的那条路 |
| 入口 | 应用读麦克风的那条路 |
| 抄一份 | 把某应用正在放的声音复制一份出来 |
| 写跳转 | 把原来的指令改成一跳，声音改道走工具 |

## 七、现在做到哪了

以下都是实机验证过的：

- 出口能按应用挑出指定那一路的声音，其余应用的声音不进麦克风；
- 入口替换后，录音应用拿到的是音乐，实测波形幅度 0.70，关掉开关后 0.001 量级；
- 打开开关时录音全是音乐，没有环境声，也没有重复样本；
- 开关关闭后原始指令被完整写回，录音立刻恢复成真实麦克风；
- 开、关全程声音服务不重启，正在放的音乐不中断；
- 先开开关再开始录音，音乐一响起就能接上；放歌中断一段时间后再放，录音同样能接上。

## 八、还差什么

- 声音服务被系统重启后钩子会丢，到界面上把开关关掉再打开即可恢复；
- 工具里的库内地址、录音流对象字段偏移按本机实测值写死，换机型要重新测；
- 系统里同时有多路录音流时，只按应用编号挑声音来源，不区分是哪一路录音。
